\begin{abstract}
Spam filters hosted in the cloud see the full content of every message they classify.
We show that a multinomial naive Bayes spam filter can instead classify messages encrypted with the additively homomorphic Paillier cryptosystem.
Naive Bayes reduces to a linear log-odds score, so the server evaluates it on the encrypted TF-IDF features with plaintext weights and returns a single ciphertext, which only the client can decrypt.
Fixed-point integer encoding makes the encrypted computation exact and hides which features are non-zero.
On the deduplicated SMS Spam Collection, the encrypted classifier reaches an accuracy of \SI{98.07}{\percent}, an F1 score of $0.922$ for spam and a ROC-AUC of $0.991$; it agrees with the plaintext model on all \num{1035} test messages, and every decrypted score equals the plaintext integer computation.
With $1000$ features and a \num{2048}-bit key, client-side encryption dominates the cost at about \SI{4}{\second} per message on one core.
A classifier trained by the server on ciphertexts performs no better than always predicting ham, whereas sending only the non-zero features would let the server classify messages as accurately as the model itself.
\end{abstract}
